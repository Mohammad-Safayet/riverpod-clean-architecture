# Routing

go_router with typed routes generated by `go_router_builder`. Every route is in `lib/app/router/routes.dart`; the router and its redirect are in `app_router.dart`.

## Navigate

```dart
const ProductsRoute().go(context);          // replace stack within the branch
ProductDetailRoute(id: 5).push(context);    // push on top
ProductDetailRoute(id: 5).go(context);      // go to the URL (/products/5)
context.pop();
```

Parameters are constructor fields, so a missing or wrong-typed parameter is a compile error. Fields not in the path become query parameters.

## Add a route

Top-level screen:

```dart
@TypedGoRoute<OrdersRoute>(path: '/orders')
class OrdersRoute extends GoRouteData with $OrdersRoute {
  const OrdersRoute();

  @override
  Widget build(BuildContext context, GoRouterState state) => const OrdersScreen();
}
```

Child of an existing route: add `TypedGoRoute<OrderDetailRoute>(path: ':id')` to the parent's `routes:` list and declare `class OrderDetailRoute extends GoRouteData with $OrderDetailRoute` (no annotation on the child class).

New bottom-nav tab: add a `TypedStatefulShellBranch<XBranch>` to `MainShellRoute`, a `class XBranch extends StatefulShellBranchData`, and a `NavigationDestination` in `features/main/presentation/screens/main_screen.dart` at the same index.

Then `make gen`.

## Session redirect

`sessionRedirect(status, location)` in `app_router.dart` is the single access rule:

- `unknown` (restoring tokens at startup) → `/splash`
- `unauthenticated` → `/login`
- `authenticated` on splash/login → `/products`

The router listens to `sessionProvider` status through a `ValueNotifier`, so it re-runs redirect without being rebuilt. Login/logout never navigate by hand: they change the session and the redirect moves the user. Public screens that need no login: allow their location in `sessionRedirect` and add a case to `test/app/router/session_redirect_test.dart`.
