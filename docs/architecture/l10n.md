# Localization and theming

## Strings

- Source files: `lib/l10n/app_en.arb` (template) and `app_bn.arb`. Generated code goes to `lib/l10n/generated/` (gitignored) on `make gen` / `make l10n`.
- Read with `context.l10n.someKey` (from `core/extensions/context_extensions.dart`).
- Key naming: `<area><Thing>`, e.g. `loginButton`, `productsTitle`, `errorTimeout`, `actionRetry`.
- Placeholders need metadata in the English file only:

```json
"productStock": "{count} in stock",
"@productStock": { "placeholders": { "count": { "type": "int" } } }
```

- Every key must exist in both files with a real translation. `tool/l10n_check.dart` (in `make check` and CI) fails on missing/extra keys, dropped `{placeholders}` and hardcoded UI strings (`Text('...')`, `labelText: '...'`, …), and warns when a translation equals the English. Mark a deliberate literal with a trailing `// l10n-ignore`.

## Language switching

`localeProvider` (`core/l10n/locale_notifier.dart`) holds the chosen `Locale`, persisted via `PreferenceManager`; `null` follows the device. `setLocale(Locale('bn'))` switches the whole app live. Adding a language: create `app_<code>.arb` with every key, then add the display name in `SettingsScreen._languageNames`.

## Theme

| What | Where | Use |
|---|---|---|
| Raw palette | `core/theme/app_colors.dart` → `Palette` | only inside theme files |
| Semantic colors | `AppColors` (`ThemeExtension`) | `context.colors.primary`, `.textSecondary`, `.error` … |
| Text styles | `AppTextStyles` (`ThemeExtension`) | `context.textStyles.title`, `.body`, `.caption` … |
| Spacing, radii, sizes | `AppValues` | `AppValues.padding`, `AppValues.radius` |
| Material theme | `AppTheme.light()` | wired in `App` |

Light only for now. Dark mode later: add `AppColors.dark`, build `AppTheme.dark()` the same way as `light()`, pass it as `MaterialApp.darkTheme`. Widgets already read semantic names, so they don't change.

Assets: put files in `assets/images/` or `assets/icons/`, run `make gen`, use `Assets.images.logo.image()` / `Assets.icons.x.svg()` from `lib/gen/assets.gen.dart`.
